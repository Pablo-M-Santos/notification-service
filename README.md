# Notification Service

Central de notificações desenvolvida para fins de estudo.

## Objetivo

Criar uma API capaz de receber eventos de diferentes sistemas e
encaminhar notificações para diferentes canais.

## Roadmap

- [x] Inicialização do projeto
- [ ] Integração com Telegram
- [ ] Persistência das notificações
- [ ] Arquitetura de Providers
- [ ] Integração com novos canais
- [ ] Processamento assíncrono
- [ ] Retry
- [ ] Dashboard

- Java

- PostgreSQL
